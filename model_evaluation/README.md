# Model Evaluation

`teacher_data/train`, `teacher_data/val`, `teacher_data/test` を使って学習と評価をまとめて実行するためのディレクトリです。

## Files

- `run_teacher_evaluation.py`: 学習、検証、テスト評価、結果保存を一括実行するスクリプト
- `results/`: 評価結果、学習済みモデル、メトリクスを保存するディレクトリ

## Usage

```bash
python3 model_evaluation/run_teacher_evaluation.py
```
